# 获取转换任务

上传的文件不是pdf进行转换pdf，可以用来查看转换的进度

### 请求语法

```
POST v2/signature/convert_task
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述   |
|---|---|--|---|------|
| task_id | 字符串|是|--| 任务id |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称 | 类型 |示例值| 描述                                                                                                                                 |
|---|---|-|------------------------------------------------------------------------------------------------------------------------------------| 
| convert_file_id | 字符串|是| 文件id，如果是pdf文件可以直接使用file_id创建签署流程                                                                                                   |
| task_status | 字符串|是| 0- 任务已提交 4 - 文档转换中 8 - 任务处理完成 2 - 下载失败 6 - 转换失败 -13 - 转换文件超时 |                        
| message | 字符串|是| 状态说明                                                                                                                               |
