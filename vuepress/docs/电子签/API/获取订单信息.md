# 获取订单信息

调用获取订单信息接口根据电子签订单号查询电子签订单（合同流程）详情，包含合同状态、签署人状态、原文件信息等

### 请求语法

```
GET v2/signature/order_info
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| signature_sn | 字符串|是|SN20250101xxxx| 电子签订单号，即创建签署流程时返回的订单号 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细[查看data响应](#data) |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### <a id='data'>data响应</a>

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| uid | 数字|21| 用户id |
| flow_name | 字符串|劳动合同| 合同名称 |
| signature_sn | 字符串|SN20250101xxxx| 电子签订单号 |
| dead_line | 数字|0| 签署截止时间戳；0=未设置 |
| template_id | 字符串|--| 合同模板ID |
| flow_id | 字符串|--| 电子签合同流程ID |
| file_id | 字符串|--| 电子签文件ID |
| origin_file_url | 字符串|--| 签署前原文件URL，可为null |
| origin_file_name | 字符串|--| 签署前原文件名，可为null |
| origin_file_ext | 字符串|pdf| 签署前原文件后缀，可为null |
| flow_description | 字符串|--| 合同流程描述 |
| flow_display_type | 数字|0| 文案类型；0=合同；1=文件；2=协议；3=文书 |
| flow_status | 字符串|PART| 合同状态，详细[查看flow_status枚举](#flow-status) |
| approve_status | 字符串|PENDING| 签署人状态，详细[查看approve_status枚举](#approve-status) |
| approved_at | 字符串|2026-01-01 12:00:00| 签署完成时间，可为null |
| mark | 字符串|--| 说明 |
| approver | 数组|[]| 签署人信息数组 |

### <a id='flow-status'>flow_status枚举</a>

| 值 | 描述|
|---|---|
| INIT | 合同创建 |
| PART | 签署中 |
| ALL | 签署完成 |
| REJECT | 拒签 |
| CANCEL | 撤回 |
| WILLEXPIRE | 即将过期 |
| DEADLINE | 已过期 |
| RELIEVED | 已解除 |
| INVALID | 已失效 |
| EXCEPTION | 异常 |
| (空) | 尚未创建流程 |

### <a id='approve-status'>approve_status枚举</a>

| 值 | 描述|
|---|---|
| PENDING | 待签署 |
| ACCEPT | 已签署 |
| REJECT | 拒绝 |
| DEADLINE | 过期未处理 |
| CANCEL | 流程已撤回 |
| STOP | 流程已终止 |
| WAITPICKUP | 待领取 |
| FILLPENDING | 待填写 |
| FILLACCEPT | 填写完成 |
| FORWARD | 已转他人处理 |
| RELIEVED | 已解除 |
| FILLREJECT | 拒绝填写 |
| EXCEPTION | 异常 |

> 仅能查询当前授权应用所属用户的订单，订单不存在时返回「未找到订单信息」

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/signature/order_info?signature_sn=SN20250101xxxx',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```
