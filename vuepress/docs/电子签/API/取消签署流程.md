# 取消签署流程

创建订单后，可以取消签署流程。电子签订单的状态为：ALL，REJECT，DEADLINE，CANCEL，RELIEVED 当前状态下不可以取消签署：

### 请求语法

```
POST v2/signature/cancel_flow
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|--|---|---|
| signature_sn | 字符串|是|--| 订单号 |
| cancel_message | 字符串|是|--| 取消说明 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |
