# 添加操作员

用来添加可以操作的员工

### 请求语法

```
POST v2/signature/cancel_flow
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型  |是否必填 |示例值| 描述|
|---|-----|--|---|---|
| user_name | 字符串 |是|--| 员工姓名 |
| mobile | 字符串 |是|--| 手机号 |
| email | 字符串 |是|--| 邮箱 |
| role | 数组  |是|--| 权限 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |


### data响应

| 名称 | 类型 |示例值| 描述        |
|---|---|-|-----------| 
| signature_admin_id | 字符串|是| 电子发票的用户id |
| uid | 字符串|是| 一号通的用户id  |
| openid | 字符串|是| openid    |
| userid | 字符串|是| userid    |
| user_name | 字符串|是| 姓名        |
| mobile | 字符串|是| 手机号       |
| email | 字符串|是| 邮箱        |
| role | 字符串|是| 规则        |
| updated_at | 字符串|是| 修改时间      |
| created_at | 字符串|是| 添加时间      |
| id | 字符串|是| 自增id      |

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/signature/cancel_flow',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode([
        'user_name' => 'xxx',
        'mobile' => '13800138000',
        'email' => 'xxx',
        'role' => [],
    ]),
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/signature/cancel_flow"))
        .header("Authorization", "Bearer-" + token)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"user_name\":\"xxx\",\"mobile\":\"13800138000\",\"email\":\"xxx\",\"role\":[]}"))
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/signature/cancel_flow", strings.NewReader(`{"user_name":"xxx","mobile":"13800138000","email":"xxx","role":[]}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
