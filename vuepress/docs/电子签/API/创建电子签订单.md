# 创建电子签订单

调用创建电子签的订单，返回订单号

### 请求语法

```
POST v2/signature/create_signature_order
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| flow_name | 字符串|否|--| 合同名称 |
| flow_description | 字符串|是|--| 合同简介 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称 | 类型 |示例值| 描述  |
|---|---|-|-----| 
| signature_sn | 字符串|是| 订单号 |


### 请求示例
 ```
 POST $HOST/v2/signature/create_signature_order
 
 {
    "flow_name":"测试的",
    "flow_description":"你好"
}

 ```

### 返回数据
~~~
{
    "status": 200,
    "msg": "ok",
    "data": {
        "signature_sn": "SN724938499580493824"
    }
}
~~~
