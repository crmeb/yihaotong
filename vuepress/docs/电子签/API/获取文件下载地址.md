# 获取文件下载地址

获取合同的下载地址，返回地址给用户下载

### 请求语法

```
GET v2/signature/describe_file_url
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述   |
|---|---|--|---|------|
| signature_sn | 字符串|是|--| 订单id |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称      | 类型 |示例值| 描述         |
|---------|---|-|------------| 
| name    | 字符串|是| 文件名称，有可能为空 |
| url    | 字符串|是| 下载链接地址     |
