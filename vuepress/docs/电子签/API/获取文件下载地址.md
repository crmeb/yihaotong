# 获取文件下载地址

获取合同的下载地址，返回地址给用户下载

### 请求语法

```
GET v2/signature/describe_file_url
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述   |
|---|---|--|---|------|
| signature_sn | 字符串|是|--| 订单id |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称      | 类型 |示例值| 描述         |
|---------|---|-|------------| 
| name    | 字符串|是| 文件名称，有可能为空 |
| url    | 字符串|是| 下载链接地址     |

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/signature/describe_file_url?signature_sn=%E4%B8%80%E5%8F%B7%E9%80%9A',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

<code-block title="Java">

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/signature/describe_file_url?signature_sn=%E4%B8%80%E5%8F%B7%E9%80%9A"))
        .header("Authorization", "Bearer-" + token)
        .GET()
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("GET", "http://sms.crmeb.net/api/v2/signature/describe_file_url?signature_sn=%E4%B8%80%E5%8F%B7%E9%80%9A", nil)
	req.Header.Set("Authorization", "Bearer-"+token)

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
