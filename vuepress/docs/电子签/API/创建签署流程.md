# 创建签署流程

使用创建的电子签订单号来创建签署流程，返回签署地址，跳转到签署页面进行签署可以为小程序，h5，pc端的链接

### 请求语法

```
POST v2/signature/create_signature_order
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型  | 是否必填 |示例值| 描述                                                                                                              |
|---|-----|------|---|-----------------------------------------------------------------------------------------------------------------|
| signature_sn | 字符串 | 是    |--| 订单号                                                                                                             |
| channel_type | 字符串 | 是    |--| 返回的签署链接地址类型 WEIXINAPP=返回小程序链接；H5=返回h5链接；PC=返回PC的链接                                                              |
| file_id | 字符串 | 是    |--| <a href='/docs/电子签/API/上传文件.html'>文件的file_id</a>或者是<a href='/docs/电子签/API/获取转换任务.html'>转换文件的convert_file_id</a> |
| userid | 字符串 | 否    |--| 操作人可以为空，可以填写，由<a href='/docs/电子签/API/添加操作员.html'>添加操作员返回字段userid获取</a>                                          |
| approvers | 数组  | 否    |--| 签署人列表[查看approvers参数](#approvers)                                                                                |
| need_sign_review | 布尔  | 否    |--| 是否需要审核                                                                                                          |
| dead_line | 数字  | 否    |--| 合同截止日期，不填写默认一年                                                                                                  |

### <a id='approvers'>approvers参数</a>

| 名称 | 类型 | 示例值          | 描述                                     |
|---|---|--------------|----------------------------------------| 
| approverType | 字符串| ORGANIZATION | ORGANIZATION=企业，PERSON=个人              |
| organizationName | 字符串| 未来科技有限公司     | approverType=ORGANIZATION必须填写，企业名称必须真实 |
| organizationOpenId | 字符串| --           | 企业的opendi,不传默认为当前企业 |
| name | 字符串| 张三           | 法人名称，也可以为签署人姓名，必须真实                    |
| mobile | 字符串| 15599558899  | 手机号，提供的手机号会给当前发送签署消息                   |
| openId | 字符串| --           | 企业员工标识，不传默认为法人|
| notChannelOrganization | 字符串| true         | 是否saas企业,只要不是当前企业签署，则为true             |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称 | 类型     |示例值| 描述  |
|---|--------|-|-----| 
| urls | 字符串/数组 |是| https://test.essurl.cn/ll0QUBRIYK |


### approvers 各种场景传参说明:
场景编号 发起方类型 签署方类型 签署方传参说明
#### 场景一 第三方子企业A员工 第三方子企业A员工
（必传）Name：签署方的名字  
（必传）Mobile：签署方的手机号  
（必传）OpenId：企业员工标识  
（必传）OrganizationName：子企业名称  
（必传）OrganizationOpenId：子企业的标识  
（固定）ApproverType：需设置为ORGANIZATION  
#### 场景二 第三方子企业A员工 第三方子企业B(不指定经办人走领取方式)
（必传）OrganizationName：子企业名称  
（必传）OrganizationOpenId：子企业的标识  
（固定）ApproverType：需设置为ORGANIZATION  
（固定）ApproverOption.FillType：需设置为1  
#### 场景三 第三方子企业A员工 第三方子企业B员工
（必传）Name：签署方的名字  
（必传）Mobile：签署方的手机号  
（必传）OpenId：企业员工标识  
（必传）OrganizationName：子企业名称  
（必传）OrganizationOpenId：子企业的标识  
（固定）ApproverType：需设置为ORGANIZATION  
#### 场景四 第三方子企业A员工 个人/自然人
（必传）Name：签署方的名字  
（必传）Mobile：签署方的手机号  
（固定）ApproverType：需设置为PERSON
#### 场景五 第三方子企业A员工 SaaS平台企业员工
（必传）OrganizationName：SaaS企业的名字  
（必传）Name：签署方的名字  
（必传）Mobile：签署方的手机号  
（不传）OrganizationOpenId：子企业的标识  
（不传）OpenId：企业员工标识  
（固定）ApproverType：需设置为ORGANIZATION  
（固定）NotChannelOrganization：需设置为True  

### 请求例子

请求参数,需要进行审核，由当前企业发起签署申请,当approvers签署的个数小于等于1的是否就可以动态增加签署人，反之则不能；
```
{
    "signature_sn": "SN727559642439221248",
    "channel_type":"WEIXINAPP",
    "file_id": "yDtOPUUckpfoxmhbUeBeo8yKtzwjwGpk",
    "need_sign_review":true,
    "approvers": [
        {
            "approverType":"ORGANIZATION",
            "organizationName":"测试众邦网络科技有限公司",
            "name":"韩--",
            "mobile":"18100000000",
            "openId":"4a60ae87cac736e9f1c8faa884131c86",
            "organizationOpenId":"d8f0cad94355e862e972c8485b2f92cd"
        }
    ]
}
```
返回小程序签署链接，由于目前need_sign_review为true，需要<a href='/docs/电子签/API/审核电子合同.html'>调用审核电子合同接口</a>

```
    "msg": "ok",
    "data": {
        "urls": "https://test.essurl.cn/ll0QUBRIYK"
    }
}
```
