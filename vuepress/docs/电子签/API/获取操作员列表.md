# 获取操作员列表

用来添加的操作员工

### 请求语法

```
GET v2/signature/operator_list
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型  | 是否必填 |示例值| 描述       |
|---|-----|------|---|----------|
| user_name | 字符串 | 否    |--| 员工姓名、手机号、邮箱，模糊查询 |
| page | 数字 | 是    |--| 页码       |
| limit | 数字  | 是    |--| 每页展示多少   |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称   | 类型  |示例值| 描述   |
|------|-----|-|------| 
| list | 数组  |是| 列表数据 |
| count  | 数字 |是| 总数   |

### list响应

| 名称 | 类型 |示例值| 描述        |
|---|---|-|-----------| 
| signature_admin_id | 字符串|是| 电子发票的用户id |
| uid | 字符串|是| 一号通的用户id  |
| openid | 字符串|是| openid    |
| userid | 字符串|是| userid    |
| user_name | 字符串|是| 姓名        |
| mobile | 字符串|是| 手机号       |
| email | 字符串|是| 邮箱        |
| role | 字符串|是| 规则        |
| updated_at | 字符串|是| 修改时间      |
| created_at | 字符串|是| 添加时间      |
| id | 字符串|是| 自增id      |
