# 获取操作员列表

用来添加的操作员工

### 请求语法

```
GET v2/signature/operator_list
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型  | 是否必填 |示例值| 描述       |
|---|-----|------|---|----------|
| user_name | 字符串 | 否    |--| 员工姓名、手机号、邮箱，模糊查询 |
| page | 数字 | 是    |--| 页码       |
| limit | 数字  | 是    |--| 每页展示多少   |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称   | 类型  |示例值| 描述   |
|------|-----|-|------| 
| list | 数组  |是| 列表数据 |
| count  | 数字 |是| 总数   |

### list响应

| 名称 | 类型 |示例值| 描述        |
|---|---|-|-----------| 
| signature_admin_id | 字符串|是| 电子发票的用户id |
| uid | 字符串|是| 一号通的用户id  |
| openid | 字符串|是| openid    |
| userid | 字符串|是| userid    |
| user_name | 字符串|是| 姓名        |
| mobile | 字符串|是| 手机号       |
| email | 字符串|是| 邮箱        |
| role | 字符串|是| 规则        |
| updated_at | 字符串|是| 修改时间      |
| created_at | 字符串|是| 添加时间      |
| id | 字符串|是| 自增id      |

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/signature/operator_list?user_name=xxx&page=1&limit=1',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

<code-block title="Java">

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/signature/operator_list?user_name=xxx&page=1&limit=1"))
        .header("Authorization", "Bearer-" + token)
        .GET()
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("GET", "http://sms.crmeb.net/api/v2/signature/operator_list?user_name=xxx&page=1&limit=1", nil)
	req.Header.Set("Authorization", "Bearer-"+token)

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
