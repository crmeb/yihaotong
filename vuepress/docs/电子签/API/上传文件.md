# 上传文件

用来上传签署合同需要的文件支持：pdf, doc, docx, jpg, png, xls, xlsx, html；如果不是pdf文件，则返回task_id自动转换pdf，这个task_id是用来查询转换进度的，需要自己保存；

### 请求语法

```
POST v2/signature/upload_file
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|--|---|---|
| file_name | 字符串|是|--| 文件名，例如：测试.pdf |
| base64_content | 字符串|是|--| 文件的base64内容 |
| file_md5 | 字符串|是|--| 文件的md5值 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称 | 类型 |示例值| 描述                                              |
|---|---|-|-------------------------------------------------| 
| file_id | 字符串|是| 文件id，如果是pdf文件可以直接使用file_id创建签署流程；有效期一个小时（超过一小时后系统不定期清理，会有部分时间差）, 有效期内此文件id可以反复使用, 超过有效期无法使用               |
| task_id | 字符串|是| 如果不是pdf文件，则返回task_id自动转换pdf，这个task_id是用来查询转换进度的 |                        |
