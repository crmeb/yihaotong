# 审核电子合同

用来审核电子合同

### 请求语法

```
POST v2/signature/flow_sign_review
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型  |是否必填 |示例值| 描述                                       |
|---|-----|--|---|------------------------------------------|
| signature_sn | 字符串 |是|--| 订单号                                     |
| review_type | 字符串 |是|--| 审核状态：PASS: 审核通过，REJECT: 审核拒绝，SIGN_REJECT:拒签 |
| review_message | 字符串 |是|--| 拒绝需要说明|

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |
