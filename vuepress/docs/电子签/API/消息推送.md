# 消息推送

由一号通服务端，给用户端推送消息；推送地址来自，在一号通授权管理-》回调设置 中的回调地址

### 请求语法

```
POST call_back_url
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 响应元素

| 名称 | 类型| 是否必填 |示例值| 描述                    |
|---|---|------|---|-----------------------|
| type | 字符串| 是    |signature_order| 类型|
| data | 字符串| 否    |--| 加密密文没有解密前为string，解密后为对象 |

### data解析后数据

| 名称      | 类型  |示例值| 描述                                                                                                                                              |
|---------|-----|-|-------------------------------------------------------------------------------------------------------------------------------------------------|
| signature_sn    | 字符串 |是| 订单号                                                                                                                                             |
| flow_status    | 字符串 |是| 状态：合同状态：INIT=合同创建，PART=合同签署中，ALL=合同签署完成，REJECT=合同拒签，CANCEL=合同撤回，WILLEXPIRE=合同即将过期，DEADLINE=合同流签(合同过期)，RELIEVED=已解除，INVALID=合同已失效，EXCEPTION=合同异常 |
| approves    | 数组 |是| 签署人列表 [查看approves参数](#approves)                                                                                                                                           |


### <a id='approves'>approves 对象参数</a>
| 名称      | 类型  |示例值| 描述  |
|---------|-----|-|-----|
| approverType    | 字符串 |是| ORGANIZATION=企业，PERSON=个人 |
| organizationName    | 字符串 |是| 企业名称 |
| organizationOpenId    | 字符串 |是| 企业的opendi,不传默认为当前企业 |
| openId    | 字符串 |是| 企业员工标识，不传默认为法人 |
| name    | 字符串 |是| 名称 |
| mobile    | 字符串 |是| 手机号 |
| notChannelOrganization    | 布尔  |是| 是否saas企业 |
| approve_status    | 字符串 |是| 签署状态：PENDING= 待签署；ACCEPT=已签署；REJECT=拒绝；DEADLINE=过期没人处理；CANCEL=流程已撤回；STOP=流程已终止；WAITPICKUP=待领取；FILLPENDING=待填写；FILLACCEPT=填写完成；FORWARD=已转他人处理；RELIEVED=已解除；FILLREJECT=拒绝填写；EXCEPTION=异常 |
| approve_message    | 字符串 |是| 签署说明 |
| approve_time    | 字符串 |是| 签署时间|
