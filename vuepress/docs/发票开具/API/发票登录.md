# 发票登录

调用发票登录接口向电子税局发起发票用户登录：不传 code 时发送税局短信验证码，传 code 时使用验证码完成登录；登录后返回该税号是否需要人脸认证，需要时请继续调用人脸识别相关接口

### 请求语法

```
POST v2/invoice/invoice_login
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| code | 字符串|否|836251| 税局短信验证码；为空=发送验证码；非空=提交验证码登录 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 发送验证码时为空；登录成功时返回 faceAuthState |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|发送成功| 请求文字描述 |

### data响应（登录成功时）

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| faceAuthState | 布尔|true| 该税号是否需要人脸认证；true=需要，请继续调用人脸识别接口 |

> 登录成功后系统会记录税局登录态；开票时若税局提示登录失效，需重新调用本接口登录

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/invoice/invoice_login',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode([
        'code' => '836251',
    ]),
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

<code-block title="Java">

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/invoice/invoice_login"))
        .header("Authorization", "Bearer-" + token)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"code\":\"836251\"}"))
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/invoice/invoice_login", strings.NewReader(`{"code":"836251"}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
