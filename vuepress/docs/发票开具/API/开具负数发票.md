# 开具负数发票

调用此接口进行开具负数发票，负数发票开具只能开具全额负数发票；

### 请求语法

```
POST v2/invoice/red_invoice_issuance/{invoiceNum}
```

### 请求头
| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### path参数
| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| invoice_num | 字符串|是|--| 发票号码 |

### 请求参数

| 名称 | 类型| 是否必填 |示例值| 描述                                                                                                   |
|---|---|------|---|------------------------------------------------------------------------------------------------------|
| apply_type | 字符串| 是    |--| 01，开票有误；02，销货退回；03，服务中止；04，销售折让；商品服务编码仅为服务时红冲原因不允许选择“02，销售退回”；如原蓝字发票商品服务编码仅为货物或劳务时红冲原因不允许选择“03，服务中止” |
| red_number | 字符串| 否    |--| 发票红字编码，需要调用申请红字发票接口返回编码；如果不传，将会自动申请红字发票                                                              |


### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|{}| 返回空 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败； |
| msg | 字符串|success| 请求文字描述 |

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/invoice/red_invoice_issuance/1',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode([
        'apply_type' => 'xxx',
        'red_number' => 'xxx',
    ]),
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

<code-block title="Java">

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/invoice/red_invoice_issuance/1"))
        .header("Authorization", "Bearer-" + token)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"apply_type\":\"xxx\",\"red_number\":\"xxx\"}"))
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/invoice/red_invoice_issuance/1", strings.NewReader(`{"apply_type":"xxx","red_number":"xxx"}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
