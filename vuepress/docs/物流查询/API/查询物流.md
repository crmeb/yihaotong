# 查询物流

调用查询物流接口可以自动识别快递公司并返回物流信息

### 请求语法

```
POST v2/expr/query
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| com | 字符串|否|--| 快递公司编码 |
| num | 字符串|是|--| 快递单号 |
| phone | 字符串|否|--| 手机号 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| ischeck | 字符串|--| -- |
| status | 字符串|--| 物流状态 |
| com | 字符串|--| 物流公司编码 |
| num | 字符串|--| 快递单号 |
| content | 数组|--| 快递详细信息,详细[查看content响应](#content) |

### <a id='content'>content响应</a>

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| time | 字符串|2023-05-27 02:40:48| 时间节点 |
| status | 字符串|【西安市】 快件已经到达 【西安南郊分部】| 物流状态信息 |

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/expr/query',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode([
        'com' => 'xxx',
        'num' => 'xxx',
        'phone' => '13800138000',
    ]),
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

<code-block title="Java">

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/expr/query"))
        .header("Authorization", "Bearer-" + token)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"com\":\"xxx\",\"num\":\"xxx\",\"phone\":\"13800138000\"}"))
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/expr/query", strings.NewReader(`{"com":"xxx","num":"xxx","phone":"13800138000"}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
