# 服务信息

调用服务信息接口返回当前账号条码查询服务的状态、余量与当前查询渠道

### 请求语法

```
GET v2/barcode/info
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

无

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细[查看data响应](#data) |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### <a id='data'>data响应</a>

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| name | 字符串|条码查询| 服务名称 |
| status | 数字|1| 服务状态；1=启用；0=锁定 |
| query_num | 数字|1000| 累计查询次数 |
| query_surp | 数字|990| 剩余查询次数 |
| provider | 字符串|apizero| 当前默认查询渠道；apizero=条码PRO；aliyun=阿里云；tencent=腾讯云 |
| provider_name | 字符串|条码PRO| 当前默认查询渠道名称 |

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/barcode/info?data=%5Bobject%20Object%5D&status=1&msg=%E8%AF%B7%E6%B1%82%E6%96%87%E5%AD%97%E6%8F%8F%E8%BF%B0',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/barcode/info?data=%5Bobject%20Object%5D&status=1&msg=%E8%AF%B7%E6%B1%82%E6%96%87%E5%AD%97%E6%8F%8F%E8%BF%B0"))
        .header("Authorization", "Bearer-" + token)
        .GET()
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("GET", "http://sms.crmeb.net/api/v2/barcode/info?data=%5Bobject%20Object%5D&status=1&msg=%E8%AF%B7%E6%B1%82%E6%96%87%E5%AD%97%E6%8F%8F%E8%BF%B0", nil)
	req.Header.Set("Authorization", "Bearer-"+token)

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
