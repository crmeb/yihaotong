# 使用说明

商品条形码查询服务，输入商品条形码（EAN-13、EAN-8、UPC-A 等编码，8~14 位数字）即可查询商品名称、品牌、规格、厂商、分类、价格、产地等商品信息。

### 服务特性

- **统一入口**：对外仅提供一个查询接口，实际由一号通后台配置的渠道（条码PRO/阿里云/腾讯云）完成查询，切换渠道无需修改代码
- **失败自动降级**：当前渠道查询失败时自动切换下一可用渠道重试，全部渠道失败本次查询不扣除余量
- **统一字段返回**：不同渠道返回的数据已统一映射为相同的字段结构，并保留渠道原始数据
- **查询记录**：每次查询均会记录条码、命中渠道、状态与返回结果，可随时查看

### 开通条形码查询服务

1. 登录[一号通工作台](https://api.crmeb.com)，进入条形码服务页面，首次使用需要开通服务
2. 开通后需要购买套餐获得查询余量，方可调用查询接口
3. 可以在服务信息接口或工作台中查看剩余查询次数，并设置余量不足的短信提醒

### 计费方式

按次计费，每次查询成功或未查到商品均消耗一次余量；因渠道故障导致查询失败时自动回退，不消耗余量。

### 使用示例

```php
<?php

use Crmeb\Yihaotong\AccessToken;
use Crmeb\Yihaotong\Factory;

$accessToken = new AccessToken([
    'access_key' => 'your access_key',
    'secret_key' => 'your secret_key',
]);

$factory = Factory::setAccessToken($accessToken);

// 条码查询
$res = $factory->barcode()->query('6901028089356');

// 查询记录
$res = $factory->barcode()->record();

// 服务信息(余量/状态/当前渠道)
$res = $factory->barcode()->info();
```
