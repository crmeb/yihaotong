# 生成商品信息

调用生成商品信息接口，根据商品主图、详情参考图和文字描述，AI生成商品发布所需资料（商品名称、简介、价格、规格、详情等），系统提供每日免费额度

### 请求语法

```
POST v2/chat/generate_goods_info
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| image | 字符串|是|https://xxx/main.jpg| 商品主图链接 |
| description | 字符串|是|蓝牙耳机 降噪 长续航| 商品描述 |
| description_image | 字符串|否|https://xxx/detail.jpg| 详情参考图，不传默认使用商品主图 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 商品资料对象，详细[查看data响应](#data) |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|ok| 请求文字描述 |

### <a id='data'>data响应</a>

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| store_name | 字符串|无线蓝牙耳机| 商品名称 |
| store_info | 字符串|--| 商品简介 |
| cate_id | 数字|1| 商品分类ID |
| unit_name | 字符串|件| 商品单位 |
| price | 数字|199.00| 商品价格 |
| ot_price | 数字|299.00| 原价 |
| cost | 数字|120.00| 成本价 |
| stock | 数字|999| 库存 |
| keyword | 字符串|--| 商品关键字 |
| description | 字符串|--| 商品详情内容 |
| items | 数组|[]| 规格数组，元素含value（规格名）与detail（规格值数组） |
| sku | 对象|{}| 规格组合与价格库存映射 |
| image | 字符串|--| 商品主图 |
| slider_image | 数组|[]| 轮播图数组 |
| description_images | 数组|[]| 详情图数组 |

> 当日调用次数在免费额度内时不扣费；超出后按实际消耗tokens扣减套餐余量，且要求已开通AI会话服务且未欠费

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/chat/generate_goods_info',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode([
        'image' => 'https://xxx/main.jpg',
        'description' => '蓝牙耳机 降噪 长续航',
        'description_image' => 'https://xxx/detail.jpg',
    ]),
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/chat/generate_goods_info"))
        .header("Authorization", "Bearer-" + token)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"image\":\"https://xxx/main.jpg\",\"description\":\"蓝牙耳机 降噪 长续航\",\"description_image\":\"https://xxx/detail.jpg\"}"))
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/chat/generate_goods_info", strings.NewReader(`{"image":"https://xxx/main.jpg","description":"蓝牙耳机 降噪 长续航","description_image":"https://xxx/detail.jpg"}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
