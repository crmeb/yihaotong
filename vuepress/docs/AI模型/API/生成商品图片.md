# 生成商品图片

调用生成商品图片接口，根据商品主图与描述AI并发生成商品主图和详情图（2K尺寸），系统提供每日免费额度

### 请求语法

```
POST v2/chat/generate_goods_image
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| image | 字符串|是|https://xxx/main.jpg| 商品主图链接（作为生成参考图） |
| description | 字符串|是|蓝牙耳机 白色背景 精修| 商品描述 |
| description_image | 字符串|否|https://xxx/detail.jpg| 详情参考图，不传默认使用商品主图 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细[查看data响应](#data) |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|ok| 请求文字描述 |

### <a id='data'>data响应</a>

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| image | 字符串|https://xxx/gen-main.jpg| 生成后的商品主图URL |
| description_image | 字符串|https://xxx/gen-detail.jpg| 生成后的商品详情图URL |

> 当日调用次数在免费额度内时不扣费；超出后每次调用扣除1个额度，且要求已开通AI会话服务且未欠费；任一图片生成失败时返回失败原因

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/chat/generate_goods_image", strings.NewReader(`{"image":"https://xxx/main.jpg","description":"蓝牙耳机 白色背景 精修","description_image":"https://xxx/detail.jpg"}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
