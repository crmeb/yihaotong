# 通用对话

调用通用对话接口进行AI对话（非流式），系统提供每日免费额度，超出免费额度后按实际消耗tokens扣除套餐余量

### 请求语法

```
POST v2/chat/chat
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| messages | 数组|是|[{"role":"user","content":"你好"}]| OpenAI风格消息数组，role支持system/user/assistant |
| max_tokens | 数字|否|2048| 最大生成tokens |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data.code | 数字|200| 200=请求成功 |
| data.data.choices | 数组|[]| 结果数组，choices[0].message.content为回复内容 |
| data.data.usage | 对象|{}| tokens消耗：prompt_tokens、completion_tokens、total_tokens |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|ok| 请求文字描述 |

> 当日调用次数在免费额度内时不扣费；超出免费额度后按 total_tokens 扣减套餐余量，且要求已开通AI会话服务且未欠费，否则返回「您今日已超过最大对话免费次数！」

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/chat/chat',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode([
        'messages' => [
            [
                'role' => 'user',
                'content' => '你好',
            ],
        ],
        'max_tokens' => 2048,
    ]),
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

<code-block title="Java">

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/chat/chat"))
        .header("Authorization", "Bearer-" + token)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}],\"max_tokens\":2048}"))
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/chat/chat", strings.NewReader(`{"messages":[{"role":"user","content":"你好"}],"max_tokens":2048}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
