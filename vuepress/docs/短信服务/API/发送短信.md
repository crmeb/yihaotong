# 发送短信

调用发送短信接口可以发送验证码短信、通知短信、营销短信；发送短信的模板id可以在获取短信模板接口中获得

### 请求语法

> 短信签名和 AccessKey 绑定的短信签名有关系

```
POST v2/sms_v2/send
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| phone | 字符串|是|--| 手机号 |
| host | 字符串|否|--| 网站地址,为了防止发送违法短信内容;联系发送人 |
| temp_id | 字符串|是|--| 短信模板ID |
| param | 字符串|是|--| 短信参数，参数内容根据模板内容变量 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细查看data响应 |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### data响应

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| content | 字符串|--| 发送的短信内容 |
| template | 字符串|--| 短信模板ID |
| id | 数字|--| 发送短信的发送记录ID |

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/sms_v2/send',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode([
        'phone' => '13800138000',
        'host' => 'xxx',
        'temp_id' => '562345',
        'param' => '{"code":"1234"}',
    ]),
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

<code-block title="Java">

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/sms_v2/send"))
        .header("Authorization", "Bearer-" + token)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"phone\":\"13800138000\",\"host\":\"xxx\",\"temp_id\":\"562345\",\"param\":\"{\\\"code\\\":\\\"1234\\\"}\"}"))
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/sms_v2/send", strings.NewReader(`{"phone":"13800138000","host":"xxx","temp_id":"562345","param":"{\"code\":\"1234\"}"}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
