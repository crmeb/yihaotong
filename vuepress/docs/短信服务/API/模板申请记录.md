# 模板申请记录

调用模板申请记录接口分页查询短信模板的申请记录及审核状态

### 请求语法

```
POST v2/sms_v2/applys
```

### 请求头

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| Authorization | 字符串|是|--| 授权TOKEN |

### 请求参数

| 名称 | 类型|是否必填 |示例值| 描述|
|---|---|---|---|---|
| account | 字符串|是|13800138000| 短信账号 |
| page | 数字|否|1| 页码，默认1 |
| limit | 数字|否|20| 每页条数，默认20 |
| temp_type | 数字|否|1| 模板类型筛选；1=验证码；2=通知；3=营销；不传=全部 |

### 响应元素

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| data | 对象|--| 返回数据，详细[查看data响应](#data-list) |
| status | 数字|200| 请求状态；200=请求成功；400=请求失败 |
| msg | 字符串|success| 请求文字描述 |

### <a id='data-list'>data响应</a>

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| count | 数字|100| 总条数 |
| data | 数组|[]| 记录数据，详细[查看data.data响应](#data-data) |

### <a id='data-data'>data.data响应</a>

| 名称 | 类型 |示例值| 描述|
|---|---|---|---| 
| id | 数字|1| 申请记录ID |
| title | 字符串|注册验证通知| 模板标题 |
| content | 字符串|您的验证码是{$code}| 模板内容 |
| temp_type | 数字|1| 模板类型；1=验证码；2=通知；3=营销 |
| status | 数字|1| 审核状态；0=待审核；1=审核通过；2=审核未通过 |
| add_time | 字符串|2026-09-10 12:00:00| 申请时间 |
| mark | 字符串|--| 备注/驳回原因 |
| sign_type | 数字|0| 提交通道；0=默认；2=阿里云；3=钉讯 |
| templ | 对象|null| 关联模板信息，含apply_id、temp_id，未关联时为null |

### 请求示例

<code-group>
<code-block title="PHP" active>

```php
<?php

$token = 'your access_token';

$ch = curl_init();

curl_setopt_array($ch, [
    CURLOPT_URL => 'http://sms.crmeb.net/api/v2/sms_v2/applys',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer-' . $token,
        'Content-Type: application/json',
    ],
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => json_encode([
        'account' => '13800138000',
        'page' => 1,
        'limit' => 20,
        'temp_type' => 1,
    ]),
]);

$response = curl_exec($ch);
curl_close($ch);

var_dump(json_decode($response, true));
```

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

String token = "your access_token";

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("http://sms.crmeb.net/api/v2/sms_v2/applys"))
        .header("Authorization", "Bearer-" + token)
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"account\":\"13800138000\",\"page\":1,\"limit\":20,\"temp_type\":1}"))
        .build();

HttpResponse<String> response = HttpClient.newHttpClient()
        .send(request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.body());
```

<code-block title="Go">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"strings"
)

func main() {
	token := "your access_token"

	req, _ := http.NewRequest("POST", "http://sms.crmeb.net/api/v2/sms_v2/applys", strings.NewReader(`{"account":"13800138000","page":1,"limit":20,"temp_type":1}`))
	req.Header.Set("Authorization", "Bearer-"+token)
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer resp.Body.Close()

	result, _ := io.ReadAll(resp.Body)
	fmt.Println(string(result))
}
```
